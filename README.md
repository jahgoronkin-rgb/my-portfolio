# my-portfolio

A polished personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile devices
- Clear portfolio sections for About, Skills, Projects, and Recommendations
- Recommendation submission form with popup confirmation
- Modern styling and improved accessibility

## Run locally
1. Open `index.html` in a browser
2. Or serve the folder with a local static server, for example:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`

## Files
- `index.html` – page structure and content
- `style.css` – modern styling and responsive design
- `script.js` – recommendation form behavior
